## Purpose

Генерация системного промпта с каталогом всех доступных проектов и их алиасами, который передаётся демону для распознавания проектов по упоминаниям в тексте запроса пользователя.

## ADDED Requirements

### Requirement: Генерация каталога проектов
Система SHALL генерировать текстовый каталог всех загруженных проектов, включающий: имя проекта, алиасы, путь к коду, список доступных MCP-серверов с их назначением. Каталог передаётся как `--append-system-prompt` при запуске демона.

#### Scenario: Каталог для двух проектов
- **WHEN** загружены проекты `alpha` (postgres, redis, git) и `beta` (postgres, git)
- **THEN** системный промпт содержит:
  - `alpha` (алиасы: project-alpha, альфа): путь /projects/alpha, MCP: pg_alpha, redis_alpha, git_alpha
  - `beta` (алиасы: project-beta, бета): путь /projects/beta, MCP: pg_beta, git_beta

#### Scenario: Каталог при отсутствии проектов
- **WHEN** ни один проект не загружен
- **THEN** системный промпт не дополняется каталогом

### Requirement: Инструкция по распознаванию проектов
Системный промпт SHALL содержать инструкцию для AI: при упоминании имени проекта или его алиаса в тексте запроса -- использовать соответствующие MCP-серверы и путь к коду. Для межпроектных операций -- использовать несколько MCP-серверов одновременно.

#### Scenario: Пользователь упоминает один проект
- **WHEN** пользователь пишет "посмотри в alpha почему тесты падают"
- **THEN** AI использует MCP-серверы `pg_alpha`, `redis_alpha`, `git_alpha` и путь `/projects/alpha`

#### Scenario: Пользователь упоминает два проекта
- **WHEN** пользователь пишет "сравни таблицу users в alpha и beta"
- **THEN** AI использует `pg_alpha` и `pg_beta` для запросов к обеим базам и сравнивает результаты

#### Scenario: Пользователь использует алиас
- **WHEN** пользователь пишет "скопируй файлы из шары в прод"
- **THEN** AI распознаёт "шара" как алиас `alpha`, "прод" как алиас `beta` и работает с обоими проектами

### Requirement: Обновление промпта при изменении проектов
При изменении списка проектов (добавление, удаление, изменение алиасов) системный промпт SHALL быть перегенерирован и передан демону при его перезапуске.

#### Scenario: Добавлен новый проект
- **WHEN** добавлен проект `gamma`
- **THEN** при следующем перезапуске демона системный промпт включает `gamma` в каталог
