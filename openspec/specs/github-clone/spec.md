## Purpose

Автоматическое клонирование публичных репозиториев GitHub по URL, указанному в конфиге проекта. Позволяет добавлять проекты просто указав URL репозитория, без ручного копирования кода на сервер.

## Requirements

### Requirement: Клонирование по github_url
Если YAML-конфиг проекта содержит поле `github_url` (публичный URL GitHub-репозитория), система SHALL автоматически клонировать репозиторий в директорию, указанную в `path`, при загрузке конфига.

#### Scenario: Первое клонирование
- **WHEN** загружен конфиг `{name: alpha, path: /projects/alpha, github_url: "https://github.com/user/repo"}` и директория `/projects/alpha` не существует
- **THEN** система выполняет `git clone https://github.com/user/repo /projects/alpha` и проект становится доступен

#### Scenario: Репозиторий уже клонирован
- **WHEN** директория `path` уже существует и является git-репозиторием
- **THEN** система выполняет `git pull` для обновления до последней версии

#### Scenario: Директория существует но не git-репозиторий
- **WHEN** директория `path` существует но не содержит `.git`
- **THEN** система SHALL пропустить клонирование, залогировать предупреждение и использовать существующую директорию как проект

### Requirement: Обработка ошибок клонирования
При ошибке клонирования (невалидный URL, сеть недоступна, репозиторий не существует) система SHALL залогировать ошибку и пропустить этот проект.

#### Scenario: Несуществующий репозиторий
- **WHEN** `github_url` указывает на несуществующий репозиторий
- **THEN** система логирует ошибку `git clone failed: repository not found` и пропускает проект

#### Scenario: Сеть недоступна
- **WHEN** `git clone` завершается с ошибкой сети
- **THEN** система логирует ошибку и пропускает проект (не падает)

### Requirement: Поддержка веток и тегов
Поле `github_url` MAY содержать ссылку на конкретную ветку или тег через синтаксис `url#branch` (например, `https://github.com/user/repo#develop`).

#### Scenario: Клонирование конкретной ветки
- **WHEN** `github_url: "https://github.com/user/repo#develop"`
- **THEN** система клонирует репозиторий и переключается на ветку `develop`

#### Scenario: Клонирование без указания ветки
- **WHEN** `github_url: "https://github.com/user/repo"` (без `#`)
- **THEN** система клонирует репозиторий с веткой по умолчанию (обычно `main`)
