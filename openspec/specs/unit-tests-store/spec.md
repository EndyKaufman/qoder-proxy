## Purpose

Обеспечивает юнит-тесты для модуля logStore — внутрипамятное хранилище логов запросов и системных событий с ограничением размера и обрезкой.

## Requirements

### Requirement: Тесты addRequest и getRequests
Система ДОЛЖНА предоставлять юнит-тесты для добавления и получения записей лога запросов.

#### Scenario: Добавление записи
- **WHEN** вызвана `addRequest` с валидной записью
- **THEN** `getRequests()` ДОЛЖЕН вернуть массив, содержащий эту запись с полями `id`, `timestamp`

#### Scenario: Записи возвращаются в обратном порядке
- **WHEN** добавлены 3 записи последовательно
- **THEN** `getRequests()` ДОЛЖЕН вернуть их в обратном порядке (последняя первая)

#### Scenario: Ограничение максимального количества записей
- **WHEN** добавлено больше записей, чем `LOG_MAX_ENTRIES`
- **THEN** старейшие записи ДОЛЖНЫ быть удалены

### Requirement: Тесты addSystem и getSystem
Система ДОЛЖНА предоставлять юнит-тесты для системных логов.

#### Scenario: Добавление системной записи
- **WHEN** вызвана `addSystem("msg", "info", "test")`
- **THEN** `getSystem()` ДОЛЖЕН вернуть запись с `message: "msg"`, `level: "info"`, `source: "test"`

#### Scenario: Записи возвращаются в обратном порядке
- **WHEN** добавлены 2 системные записи
- **THEN** `getSystem()` ДОЛЖЕН вернуть последнюю первой

### Requirement: Тесты clearRequests и clearSystem
Система ДОЛЖНА предоставлять юнит-тесты для очистки логов.

#### Scenario: clearRequests очищает все записи
- **WHEN** вызвана `clearRequests()`
- **THEN** `getRequests()` ДОЛЖЕН вернуть пустой массив

#### Scenario: clearSystem очищает все записи
- **WHEN** вызвана `clearSystem()`
- **THEN** `getSystem()` ДОЛЖЕН вернуть пустой массив

### Requirement: Тесты обрезки (truncation)
Система ДОЛЖНА предоставлять юнит-тесты для обрезки длинных payload-записей.

#### Scenario: Длинная строка обрезается
- **WHEN** `requestPayload` превышает `LOG_BODY_MAX_BYTES`
- **THEN** сохранённая запись ДОЛЖНА быть обрезана и содержать маркер `…[truncated]`

#### Scenario: Короткая строка не обрезается
- **WHEN** `requestPayload` короче `LOG_BODY_MAX_BYTES`
- **THEN** запись ДОЛЖНА быть сохранена полностью

#### Scenario: null значение не обрезается
- **WHEN** `requestPayload` равен null
- **THEN** сохранённое значение ДОЛЖНО быть null
